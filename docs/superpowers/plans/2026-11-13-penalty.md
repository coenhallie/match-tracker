# Penalty Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A human's "Penalty" plays a centre card, then a penalty scene that waits up to 20 s for "Penalty scored" or "Penalty missed", which plays the kick, holds, and fades back to the live pitch; "Penalty scored" plays this in place of the goal.

**Architecture:** The labels are read in analysis (`penaltyLabels.ts`), which also takes the penalty's spellings out of the goal's labels when asked. A `Penalty` moment in director (built as the free kick is: its own module behind `Moment`) runs the phases card, waiting, kick, holding, leaving, and hands render a `PenaltyIndicator`; render (`penalty.ts`) draws the card with `drawIconCard` and the scene from Figma's artwork, fixed to the frame. The director decides what it takes over from, and a flashback clip's director never plays it.

**Tech Stack:** TypeScript (strict, no semicolons, single quotes), Vitest, canvas 2D, oxlint.

**Spec:** `docs/superpowers/specs/2026-11-13-penalty-design.md`

## Global Constraints

- Labels, through `actionName`, human only: penalty `['penalty']`; scored `['penalty scored', 'penaltyscored', 'penalty goal', 'penaltygoal', 'penalty kick scored', 'penalty kick goal', 'scored penalty']` (moved out of `GOAL_LABELS`, which keeps `'goal'`); missed `['penalty missed', 'penaltymissed', 'missed penalty', 'penalty kick missed']`.
- Layer `penalty`, on by default, listed after `throwInBanner`. Moments `penalty`, `penaltyScored`, `penaltyMissed`.
- Words: `penalty` "PENALTY" / 点球 (card title and layer name); `penaltyWaiting` "PENALTY.." / 点球……; `penaltyScored` "SCORED!" / 罚进了！; `penaltyMissed` "MISSED!" / 罚丢了！. Layer hint en "When a penalty is given, the kick and whether it went in", zh "判罚点球时，展示罚球过程及结果".
- Timing (render/penalty.ts): `PENALTY_CARD_MS = 2400` (fades included, in and out as `LABEL_CARD_IN_MS`/`LABEL_CARD_OUT_MS`), `PENALTY_SCENE_IN_MS = 500`, `PENALTY_WAIT_S = 20` (clock), `PENALTY_KICK_MS = 700`, `PENALTY_MISS_ON_MS = 500`, `PENALTY_RESULT_IN_MS = 300`, `PENALTY_HOLD_MS = 3000`, `PENALTY_OUT_MS = 600`; by hand, waiting lasts `LABEL_CARD_DEMO_MS`.
- Layout: Figma 1600 × 1100 design px through `designUnit`, design (800, 550) on the pitch's middle, fixed to the frame; every position, size and motion value as the spec's "What the viewer sees" gives it.
- Artwork: SVG exported from Figma file `a1DQtbTjxZYWYKecizCHkf`, nodes 63:1004 (card icon), 136:3140 (goal), 136:2918 (keeper), 136:3192 (keeper diving), 136:2913 (spinner ball), 136:3191 (ball); inlined in `src/assets/icons.ts`; nothing bitmap (a keeper that exports as an image is redrawn as a vector to match it).
- Size budget 65 kB gzipped for `dist/index.js` (`BUDGET = 65_000`).
- No em dashes; no agent attribution; goldens and baseline snapshots unchanged; `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm run size` pass at each task's end.

## Review Focus

1. "Penalty scored" with the layer on, then "Player scored" 2 s later: nothing more plays, and no goal (Task 4).
2. "Penalty" and its result on one record (a fast labeller, records merged by `withHiddenLabels`): the card, then straight into the kick (Task 4).
3. The live stream stalls while the scene waits: the clock stands still, so the scene would hang. It also leaves after `2 * PENALTY_WAIT_S` of animation frames in waiting, whatever the clock (Task 4).
4. The `penalty` layer switched off while the scene shows: it ends at once, and a "Penalty scored" after plays the goal (Task 5).
5. The zoom near goal zoomed in when a Penalty comes: it eases out to the whole pitch while the penalty shows, as for a centre card, and back in after (Task 5).

**Interfaces:**
- Consumes: Task 1's `PenaltyResult`; Task 2's words and icons.
- Produces:
  ```ts
  export interface PenaltyIndicator {
    card: number            // 0..1, the card's fade, and how far players and ball are faded
    scene: number           // 0..1, the scene's fade
    team: string | null
    waitMs: number          // since the scene came in: the spinner and the sway

    kick: number            // 0..1 through the kick

    still: boolean          // reduced motion: no turning ball, no sway
  }
  export interface PenaltyPose { ball: { x: number; y: number; size: number; turnDeg: number; alpha: number }; ballShadow: Ellipse; keeper: { x: number; y: number; turnDeg: number; dive: number }; keeperShadow: Ellipse; trail: number }
  ```

### Task 4: The penalty moment

**Files:**
- Create: `src/director/penalty.ts`
- Modify: `src/director/director.ts` (construct it; detect after the goal in `frameChanged`; request, step, stop, reset with the others; `value()` into `FrameLayers.penalty`), `src/director/goal.ts` (`detect` passes `!this.ctx.layers().penalty` to `isGoalFrame` and `goalLabelTeam`)
- Test: `test/director/penalty.test.ts` (through `FakeReplay`, as `freeKick.test.ts`), `test/director/goal.test.ts`, `test/director/goalScorer.test.ts`

**Interfaces:**
- Consumes: Task 1's `penaltyLabels`, `isGoalFrame(frame, penaltyIsGoal)`; Task 3's `PenaltyIndicator` and timings.
- Produces:
  ```ts
  export type PenaltyPhase = 'card' | 'waiting' | 'kick' | 'holding' | 'leaving'
  export class Penalty implements Moment {
    constructor(ctx: MomentContext, plays: boolean)   // false: a flashback clip's director, which never plays it
    get active(): boolean
    get phase(): PenaltyPhase | null
    /** On each new record at `time`: true when its labels start it or move it on. Notes what is labelled either way. */
    detect(frame: Frame, time: number): boolean
    /** Played by hand: the card and waiting, or the scene straight into that kick, for `team`. */
    play(kind: 'penalty' | PenaltyResult, team: string | null, time: number): void
    step(ms: number): MomentStep
    stop(): boolean
    reset(): void
    value(): PenaltyIndicator | undefined
  }
  ```
- Rules, each a test: a new "Penalty" (not on the record before) starts the card with its team, and the clock wait; a second one restarts it. A new result while waiting or during the card: the kick (after the card and the scene's fade, if it came during the card), with the Penalty's team. A result with nothing showing: the scene in, the kick at once, the result's team. A result while kicking, holding or leaving: ignored. Waiting `PENALTY_WAIT_S` on the clock, or `2 * PENALTY_WAIT_S` of `step` ms (a stalled stream): leaving. Not during playback (`!ctx.playback()`), off its layer, or `plays` false: nothing starts, labels noted. Reduced motion: no fades, the kick shown at its end for the hold.
